### Topic 42 — CI/CD Fundamentals

- CI = automatically validate code changes.
- Continuous Delivery = release is ready for deployment.
- Continuous Deployment = release automatically goes live.
- GitHub Actions runs workflows triggered by events.
- Workflow files live in `.github/workflows/`.
- A runner executes workflow jobs.
- CI runners are separate from development and production machines.
- Failed CI should prevent an automated deployment.
